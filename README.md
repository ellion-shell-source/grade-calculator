# 📊 Універсальний Калькулятор Переведення Балів

Зручний веб-додаток для викладачів, вчителів та студентів, який дозволяє миттєво переводити бали з будь-якої системи оцінювання у 3-бальну (або будь-яку іншу кастомну) шкалу.

## 🚀 Як опублікувати на GitHub Pages

1. Створіть новий репозиторій на GitHub (наприклад, `grade-calculator`).
2. Завантажте файли `index.html`, `style.css`, `script.js` та `README.md` у свій репозиторій.
3. Перейдіть у **Settings** (Налаштування репозиторію) -> **Pages**.
4. У розділі **Build and deployment** вибрати:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (або `master`) / folder `/ (root)`.
5. Натисніть **Save**. 

За кілька секунд у верхній частині сторінки з'явиться пряме посилання на ваш калькулятор вида: `https://ваше-ім'я.github.io/grade-calculator/`.
